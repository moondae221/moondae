안내 및 유의사항

🍀 꼭 확인해 주세요
  • 상세한 견적 안내와 원활한 상담을 위해, 양식 미작성 시 답변이 제한될 수 있는 점 양해 부탁드립니다.
  • 타 작가님의 작업물을 해당 작가님 동의 없이 무단 첨부하거나, 제 작업물을 참고용으로 가져가지 말아주세요.
  • 기존 작업물과 동일하거나 유사한 카피 작업은 진행하지 않습니다. 이미 활동 중인 다른 버튜버분들의 개성을 존중해 드리고자 함이니 양해 부탁드립니다.
  • 타 작가님께 추가 작업 맡기실 경우 사전에 반드시 제게 말씀해 주시고 비공개 요청 부탁드립니다.
  • 페이셜 트래킹(52 페이셜)을 원활하게 사용하기 위해서는 Face ID가 가능한 아이폰/아이패드가 반드시 필요합니다.
  • 상담 및 견적 안내 받으신 뒤 작업 진행을 하지 않으셔도 괜찮으나, 의사가 없으실 경우 꼭 말씀 부탁드리겠습니다.
  • 원화 기반 성형은 전달해주신 원화를 최대한 그대로 구현해드리는 작업입니다. 원화와 크게 다른 방향으로 수정을 요청하실 경우 추가 금액이 발생할 수 있으니, 신청 전 최대한 마음에 드시는 원화로 준비해 주시면 감사하겠습니다.
  • 모든 작업은 문의 순서가 아닌 입금 확인 순서로 예약이 확정됩니다. (개인작 포함)
  • 결제 전 먼저 문의를 통해 일정과 견적을 확인 후 결제 부탁드립니다.
  • BOOTH 상품 이용 시 방송·상업적 이용 가능 여부, 2차 가공, 배포, 사용 범위 등을 반드시 직접 확인해 주세요. 확인하지 않아 발생하는 문제에 대해서는 작가가 책임지지 않습니다.
  • 작업에 사용되는 BOOTH 파츠는 의뢰자와 작가 모두 보유해야 합니다. 작가가 미보유한 파츠나 베이스는 '선물하기' 기능을 통해 전달 부탁드립니다.
  • 전달해주신 기프트는 환불이 불가능합니다. 보유 여부 확인을 위해 링크 먼저 전달 부탁드립니다.
  • 상담 진행 후 작가 역량이 부족한 작업일 경우 정중히 거절될 수 있는 점 양해 부탁드립니다.
  • 컨펌 단계에서 24시간 이내 답변이 없을 경우 다음 분 작업 먼저 시작합니다. 컨펌 지연 시 다음 일정에 차질이 생기므로 빠른 답변 부탁드립니다.
  • 페이셜 작업 시작 이후에는 성형 수정이 불가능합니다. 이후 수정을 원하실 경우 별도의 추가 비용이 발생합니다.
  • 기본 수정 횟수 초과 시, 1회당 10,000원의 추가 비용이 발생합니다.
  • 작업 마감 후 성형 또는 페이셜 수정 필요 시 추가금액이 발생됩니다. 금액대가 높으니 불필요한 금액이 발생되지 않도록 각 단계에서 꼭 꼼꼼한 확인 부탁드립니다.
  • 작업물은 완료 후 1개월간 보관하며 이후에는 삭제됩니다. 삭제 후 재전송 어려우므로 꼭 잘 보관해주셔야 합니다.
  • 별도 요청이 없으실 경우 작업 완료 후 포트폴리오에 바로 게시합니다. 아바타 공개 이후 게시 원하실 경우 사전에 말씀 부탁드립니다.
